# Reverse Engineering Tooling Changelog - 2026-05-22

Purpose: document reversible infrastructure changes made while auditing the
RaceMenu/SKEE face morph bug.

## Changed

- `ReverseEngineering/tools/BethesdaGhidraScripts/scripts/commonlibsse/address_library.py`
  - Changed `AddressLibrary.load_all(self, base_path)` to
    `AddressLibrary.load_all(self, base_path, se_version=None, ae_version=None)`.
  - Reason: the local `parse_commonlib_types.py` already calls `load_all` with
    `se_version` and `ae_version`; without accepting those kwargs, the official
    BGS build pipeline fails before generating `CommonLibImport_SE.py`.
  - Behavior impact: none for address selection in this local checkout; the
    values are accepted but not used.
  - Revert: remove the two optional parameters.
